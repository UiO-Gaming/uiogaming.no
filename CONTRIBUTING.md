# Huskeliste for bidrag

- Sørg for å formatere koden med Prettier (`npm run format`)

- Sjekk at koden ikke har lint-feil (`npm run lint`)

- Sjekk om nettsiden bygges uten problemer (`npm run build`)

- Formatering, linting, typesjekk og bygg kjøres også automatisk på alle pull requests

- Commit messages samt issues skal helst være skrevet på engelsk

- Kode skal skrives på engelsk. Det vil si variabelnavn osv.

- Nettsiden finnes på både norsk og engelsk. Tekst som vises til bruker skal ikke skrives rett i komponentene, men legges inn i både [messages/no.json](messages/no.json) og [messages/en.json](messages/en.json)
